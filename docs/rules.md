## 一、怎么玩（30 秒讲清）

你是那块被一僧一道带入红尘的**顽石**。石上的《石头记》字迹模糊了，前二十回每回一处，你要在 **20 个关键时刻**化身宝玉、黛玉、宝钗、凤姐、贾雨村、秦可卿、袭人、秦钟等人物，替他们做出选择。

- **选得和原著一样 = 还原成功，得分。** 注意：不是选"对的""好的"，而是选"原著里真正发生的"——比如贾雨村的选择，并不光彩。
- 选错了也不会卡住：先看一句「平行世界」（这样选故事会怎样），再看石上原文和一句解读，然后继续。
- 最后还有 **3 道「石上回顾」**，要把游戏里前后两处原文、旁白或解读连起来想（伏笔与揭晓、对联与情节、人物的公与私）——**跳过剧情会丢分**（比赛版不能存档读档，也没有「回想」可以翻历史记录）。答错时会显示正确答案。

## 三、比赛方式

**单人竞技，每人一台设备，独立作答。** 一场房间对应一次课堂比赛，昵称在本场内唯一；每个参赛身份只保留一份正式成绩。

- 主持人在 `/admin` 创建房间后展示二维码/房间码；玩家在游戏主页填写昵称加入，免注册，在主页房间面板里等待统一开赛，不跳转独立比赛页面。
- 开赛后不能新增参赛身份。作答先由服务器确认，再继续剧情；已提交答案不可改选。
- 正式比赛从主持人点击「开始比赛」起统一计时，**包含开场和加载时间**。自由游玩仍从剧本【计时开始】计时，两种用时不能混排。

**排名规则：先比总积分，同分比用时（按整秒，短者胜）；两者完全相同则并列，下一名次跳过，例如 1、1、3。** 比赛中公示实时成绩，收卷后才确定最终名次。

## 四、现场流程（15 分钟）

| 时间 | 事项 |
|---|---|
| 开赛前 | 主持人在 `/admin` 创建房间、核对名单并打开投影计分板；玩家用同一浏览器在主页加入，留在房间面板候场 |
| 0:00 | 主持人确认「开始比赛」，服务器开始统一计时；玩家在原游戏主页进入正式一局，点击「开始游戏」 |
| 进行中 | 计分板约每 2 秒更新积分、进度和完成状态；主持人巡场，无需手工录入成绩 |
| 完成时 | 系统记录总分、还原题数、用时和称号；完成基础分只加一次；可继续阅读结尾 |
| 15:00 | 自动收卷。未完成者取截止前服务器确认的积分，用时记为 15:00，也进入最终排名 |

主持人可以确认**提前结束**；未完成者仍上榜，用时记为全场实际经过时间。结束后不能补答或覆盖成绩。断网不暂停比赛时间，未获服务器确认的答案不计入。

## 七、常见问题

- **不小心关了网页或刷新了？** 用原浏览器重新打开本局地址，或在主页「加入比赛」面板的本机记录里回到原房间，进入游戏后点「继续游戏」。计时不会重置，已提交答案也不能改选；存档稍落后时，只能继续原来的选项。
- **能重新开始刷分吗？** 正式比赛不提供重开、读档或导入存档，服务器也不接受覆盖已提交答案。自由游玩可以重开，但成绩不会进入比赛房间。
- **换设备、清理浏览器数据或用了无痕模式？** 可能丢失参赛凭证和本地进度，无法在新浏览器恢复，请全程使用同一浏览器；主持人也一样。
- **怎么保证公平？** 使用昵称并由主持人核对名单、巡场。服务器保存正式答案和分数，但免注册不等于实名考试，不能防止另换身份报名或查看静态剧本。
- **手机能玩吗？** 能，横屏体验更好；课堂比赛建议用电脑。
- **题目依据哪个版本？** 维基文库《红楼梦》汇校本（前八十回以庚辰本为底本），引文逐句核对过，见 `docs/红楼梦前20回详细总结与引文核对.md`。其他版本个别字句不同（如判词「堪怜咏絮才」、托梦「三春去后诸芳尽」、太虚幻境对联「风月债难偿」），以本游戏所用底本为准。内容严格限定在第 1–20 回。
