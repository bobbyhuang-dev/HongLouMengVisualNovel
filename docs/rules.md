# 《红楼抉择》规则说明书

> 《红楼梦》第 1–20 回 · 剧情分支模拟 · 竞速还原赛
> 游戏链接：https://bobbyhuang-dev.github.io/HongLouMengVisualNovel/　　单局约 10 分钟　　免登录，浏览器打开即玩

## 一、怎么玩（30 秒讲清）

你是那块被一僧一道带入红尘的**顽石**。石上的《石头记》字迹模糊了，你要在 **13 个关键时刻**化身宝玉、黛玉、宝钗、凤姐、贾雨村等人物，替他们做出选择。

- **选得和原著一样 = 还原成功，得分。** 注意：不是选"对的""好的"，而是选"原著里真正发生的"——比如贾雨村的选择，并不光彩。
- 选错了也不会卡住：先看一段「平行世界」（这样选故事会怎样），再看石上原文和一句解读，然后继续。
- 最后还有 **3 道「石上回顾」**，只考游戏里出现过的原文和解读——**跳过剧情会丢分**。

## 三、比赛方式

两种赛制任选，规则相同：

- **小组赛**：每组一台电脑。组员轮流操作（每幕换一个人点鼠标），其他人可以一起读、一起讨论。
- **个人赛**：每人一台电脑，独立作答。

**排名规则：先比总积分，积分相同再比用时（用时短者胜）。** 抢快没有用，读准才赢。

## 四、现场流程（10 分钟）

| 时间 | 事项 |
|---|---|
| 开赛前 | 各电脑打开游戏链接，停在标题页；主持人读一遍「怎么玩」 |
| 0:00 | 主持人喊「开始」，各组/各人同时点「开始游戏」，读完开场规则后出现【计时开始】，右上角开始计时 |
| 进行中 | 计分员巡场，确认没有人重开 |
| 完成时 | 看到结算页（屏幕中央红底大字「积分 · 用时」）立即举手，计分员把积分和用时记到**积分公示板** |
| 10:00 | 未完成的以当前右上角积分计，用时记为 10:00 |

## 七、常见问题

- **不小心关了网页？** 重新打开，点「继续游戏」接着玩，计时不会重置。
- **回到标题重新开始？** 会重新计时，按新的一局算。
- **手机能玩吗？** 能，横屏体验更好；课堂比赛建议用电脑。
- **题目依据哪个版本？** 人民文学出版社通行本（前八十回以庚辰本为底本），内容严格限定在第 1–20 回。
