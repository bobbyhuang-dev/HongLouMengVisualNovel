# 《红楼抉择》策划案

> 对应课堂项目：《红楼梦》1–20 回主题游戏设计 · 电脑端方向「红楼剧情分支模拟」
> 设计要求原件：`docs/红楼梦游戏设计项目计划.pdf`；剧情范围：`docs/story-outline.md`；原文依据：`docs/sources/excerpts.md`

## 一、一句话玩法

玩家扮演那块被一僧一道携入红尘的**顽石**。石上所记《石头记》字迹模糊，玩家要在 13 个关键时刻**轮流化身书中人物**做出选择：选得与原著一致即为「还原」，按难度得分；选错则先看一段「平行世界」走向，再揭示石上原文与解读。通关后按**还原度**评出称号。

- 平台：网页（WebGAL 引擎），浏览器打开链接即玩，免登录。
- 课堂形式：竞速赛——每组（或每人）一台电脑同时开局，**先比积分，同分再比用时**；画面右上角常驻「积分 · 用时」。
- 单局时长：约 10 分钟（13 个节点 × 约 40 秒 + 开场/幕间/石上回顾/结算）。
- 核心规则一句话：**不是选"对"的，而是选"原著里发生的"。**
- 防跳剧情：终章「石上回顾」三道题只考游戏中出现过的原文与解读，跳过剧情就会丢分；用时只在同分时起作用，抢快不如读准。

## 二、结构

```
开场（石上偈语·规则·计时开始） → 第一幕 缘起（1–5回） → 第二幕 暗流（6–12回）
→ 第三幕 一丧一喜（13–16回） → 第四幕 大观园（17–20回） → 石上回顾（3题） → 结算（积分·还原度·用时·称号）
```

每个节点固定四拍，保证节奏紧凑：

1. **场景**：1 句旁白交代情境 + 1–2 句原著对白；
2. **抉择**：屏幕标明「第X回 · 你是某某 · 难度」，三选一；
3. **分支**：选错时出现 1 句「平行世界」——这样选，故事会走向哪里；
4. **还原**：石上原文（原著原句）+ 1 句解读（人物性格/情节内涵/文化典故），并公示当前积分与连击。

未设节点的回目（第2、9、10、14、16、19回等）在幕间以 1–2 句旁白串联，保证剧情线完整。

## 五、积分规则

| 类别 | 规则 | 分值 |
|---|---|---|
| 基础分 | 完成一局 | +1 |
| 表现分（难度分级） | 还原一道「易」/「中」/「难」 | +1 / +2 / +3 |
| 连击奖励 | 每连续还原 3 题（13 个剧情节点内计） | 额外 +1 |
| 石上回顾 | 每答对 1 题 | +2 |
| 满分 | 剧情 4 易 + 6 中 + 3 难 = 25；连击最多 4；基础 1；回顾 6 | **36** |

- **还原度** = 还原的剧情节点数 ÷ 13。
- **积分公示**：右上角常驻「积分 · 用时」；每题揭晓时显示「本题得分 · 当前积分 · 连击进度」；结算页显示总分、还原度、用时与称号。
- **排名**：总积分高者胜；同分时用时短者胜。
